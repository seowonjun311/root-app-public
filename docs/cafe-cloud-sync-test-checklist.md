# ROOT 저장 카페 클라우드 동기화 실기기 테스트

현재 상태:

- V34 정적 설치 완료
- TypeScript 검사 완료
- 실기기 및 Firestore 통신 검증 보류

## 1. 로그인 사용자 저장

- [ ] Google 로그인 상태에서 카페를 저장한다.
- [ ] 저장 직후 로컬 목록에 카페가 표시된다.
- [ ] 로그에 `SAVED CAFE CLOUD SYNC DONE`이 표시된다.
- [ ] Firestore `users/{uid}` 문서에 `savedCafeData`가 생성된다.
- [ ] `savedCafeData.entries`에 저장한 카페가 포함된다.

## 2. 수정 동기화

- [ ] 저장 카페 상세 화면에서 테마나 메모를 수정한다.
- [ ] 목록에 수정 내용이 즉시 반영된다.
- [ ] Firestore의 동일한 `placeId` 항목도 수정된다.
- [ ] 중복 카페 항목이 생기지 않는다.

## 3. 삭제 동기화

- [ ] 카페를 삭제하면 목록에서 즉시 사라진다.
- [ ] Firestore `entries`에서도 삭제된다.
- [ ] `deletedEntries`에 삭제 시각이 기록된다.
- [ ] 다른 기기에서 동기화해도 삭제한 카페가 되살아나지 않는다.

## 4. 새 기기 복원

- [ ] 같은 Google 계정으로 새 기기에 로그인한다.
- [ ] 저장한 카페 목록 화면을 연다.
- [ ] 서버 카페가 로컬 목록으로 복원된다.
- [ ] 수정 내용과 삭제 상태도 동일하게 복원된다.

## 5. 게스트와 계정 분리

- [ ] 게스트 상태에서는 Firestore 쓰기를 시도하지 않는다.
- [ ] 게스트 카페는 기기 로컬에 저장된다.
- [ ] 게스트에서 Google 로그인하면 기존 게스트 카페가 한 번만 이전된다.
- [ ] 다른 Google 계정의 저장 카페가 섞이지 않는다.

## 6. 오프라인 복구

- [ ] 네트워크가 없어도 로컬 저장과 삭제가 작동한다.
- [ ] 네트워크 오류로 앱이 종료되지 않는다.
- [ ] 네트워크 복구 후 목록을 다시 열면 서버 동기화가 재시도된다.
