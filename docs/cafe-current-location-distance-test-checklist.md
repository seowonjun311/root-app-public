# ROOT 저장 카페 현재 위치·거리 실기기 테스트

현재 상태:

- V39 정적 검사 완료
- TypeScript 검사 완료
- 실기기 위치 권한·거리 검증 보류

## 위치 권한

- [ ] 지도 진입만으로 위치 권한창이 자동 표시되지 않는다.
- [ ] 내 위치 버튼을 눌렀을 때 전경 위치 권한을 요청한다.
- [ ] 권한 허용 후 현재 위치로 지도가 이동한다.
- [ ] 권한 거부 시 앱이 종료되지 않고 안내창이 표시된다.
- [ ] 위치 확인 실패 시 다시 시도할 수 있다.
- [ ] 위치를 이미 확인한 뒤 버튼을 누르면 현재 위치로 다시 이동한다.

## 현재 위치 표시

- [ ] 권한 허용 후 지도에 사용자 위치가 표시된다.
- [ ] 사용자 위치 버튼의 선택 상태가 구분된다.
- [ ] 위치 조회 중 진행 표시가 나타난다.
- [ ] 기존 카페 마커가 그대로 표시된다.

## 거리 계산

- [ ] 선택 카페 카드에 현재 위치부터의 거리가 표시된다.
- [ ] 1km 미만 거리는 m 단위로 표시된다.
- [ ] 1km 이상 거리는 km 단위로 표시된다.
- [ ] 다른 마커를 누르면 거리가 즉시 갱신된다.
- [ ] 현재 위치를 다시 확인하면 거리가 갱신된다.
- [ ] 위치 권한이 없을 때 거리 배지가 표시되지 않는다.

## 내 주변 필터

- [ ] 위치 확인 전에는 거리 필터 안내 버튼이 표시된다.
- [ ] 위치 확인 후 전체·1km·3km·5km·10km·30km 필터가 표시된다.
- [ ] 각 거리 필터가 올바르게 작동한다.
- [ ] 거리 필터 결과가 가까운 카페 순으로 정렬된다.
- [ ] 검색·관계·대표 테마·거리 필터를 함께 적용할 수 있다.
- [ ] 거리 필터가 적용 필터 개수에 포함된다.
- [ ] 초기화 시 거리 필터도 전체로 돌아간다.

## 지도 결과

- [ ] 거리 조건 변경 후 결과 마커가 자동으로 화면에 맞춰진다.
- [ ] 결과가 없을 때 안내 카드가 나타난다.
- [ ] 현재 조건의 전체 보기 버튼이 작동한다.
- [ ] 선택된 카페가 조건에서 제외되면 유효한 카페로 선택이 변경된다.
- [ ] 카페 상세 보기·수정 이동이 유지된다.

## 기존 기능 회귀 테스트

- [ ] V37 지도 화면과 마커가 유지된다.
- [ ] V38 지도 검색·관계·대표 테마 필터가 유지된다.
- [ ] 목록 버튼과 뒤로가기 버튼이 작동한다.
- [ ] 오프라인에서도 로컬 저장 카페가 표시된다.
- [ ] 위치 권한을 거부해도 검색·필터·상세 기능은 사용할 수 있다.
