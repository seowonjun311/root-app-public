# ROOT 카페 즐겨찾기 폴더·나만의 목록 실기기 테스트

현재 상태:

- V40 정적 검사 완료
- TypeScript 검사 완료
- 실기기 폴더·목록 검증 보류

## 폴더 진입

- [ ] 저장 카페 목록의 `폴더` 버튼이 작동한다.
- [ ] 폴더 화면의 뒤로가기 버튼이 작동한다.
- [ ] 폴더 화면을 나갔다 돌아오면 최신 내용이 표시된다.
- [ ] 저장 카페가 없어도 폴더 화면이 종료되지 않는다.

## 폴더 만들기

- [ ] 새 폴더 버튼이 작동한다.
- [ ] 폴더 아이콘을 선택할 수 있다.
- [ ] 폴더 이름을 입력할 수 있다.
- [ ] 빈 이름은 저장되지 않는다.
- [ ] 같은 이름의 폴더를 중복 생성할 수 없다.
- [ ] 폴더 이름은 최대 20자로 제한된다.
- [ ] 폴더는 최대 30개까지 만들 수 있다.
- [ ] 만든 폴더가 목록 최상단에 표시된다.

## 폴더 수정·삭제

- [ ] 폴더 이름을 수정할 수 있다.
- [ ] 폴더 아이콘을 수정할 수 있다.
- [ ] 수정 후 폴더 목록과 상세 제목이 갱신된다.
- [ ] 폴더 삭제 확인창이 표시된다.
- [ ] 폴더를 삭제해도 저장 카페 자체는 삭제되지 않는다.
- [ ] 현재 보고 있는 폴더를 삭제하면 폴더 목록으로 이동한다.

## 카페 담기

- [ ] 폴더를 누르면 저장 카페 선택 화면이 열린다.
- [ ] 저장 카페를 폴더에 담을 수 있다.
- [ ] 담긴 카페를 폴더에서 뺄 수 있다.
- [ ] 담긴 카페가 목록 위쪽에 표시된다.
- [ ] 한 카페를 여러 폴더에 동시에 담을 수 있다.
- [ ] 담기 버튼을 연속으로 눌러도 중복 항목이 생기지 않는다.
- [ ] 카페 카드를 누르면 상세 보기·수정 화면이 열린다.

## 폴더 안 검색

- [ ] 카페명으로 검색할 수 있다.
- [ ] 주소로 검색할 수 있다.
- [ ] 관계와 대표 테마명으로 검색할 수 있다.
- [ ] 카페 테마명과 메모로 검색할 수 있다.
- [ ] 검색어 지우기 버튼이 작동한다.
- [ ] 검색 결과 수와 폴더에 담긴 수가 표시된다.

## 폴더 요약

- [ ] 전체 폴더 수가 표시된다.
- [ ] 저장 카페 수가 표시된다.
- [ ] 어느 폴더에도 없는 미분류 카페 수가 표시된다.
- [ ] 각 폴더의 카페 수가 표시된다.
- [ ] 각 폴더에 담긴 카페명이 최대 3개 미리 표시된다.

## 로컬·클라우드 저장

- [ ] 게스트 상태에서도 폴더 만들기와 카페 담기가 작동한다.
- [ ] 로그인 후 게스트 폴더가 현재 사용자에게 이어진다.
- [ ] 로그인 상태에서 앱을 재실행해도 폴더가 유지된다.
- [ ] 다른 기기에서 같은 계정으로 로그인하면 폴더가 복원된다.
- [ ] 오프라인에서 만든 폴더가 로컬에 유지된다.
- [ ] 인터넷 복구 후 폴더와 카페 분류가 동기화된다.
- [ ] 다른 기기에서 삭제한 폴더가 다시 나타나지 않는다.
- [ ] 저장 카페를 삭제한 뒤 폴더 화면을 열면 남은 분류가 정리된다.
