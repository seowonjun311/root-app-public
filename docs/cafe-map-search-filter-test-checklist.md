# ROOT 저장 카페 지도 검색·필터 실기기 테스트

현재 상태:

- V38 정적 검사 완료
- TypeScript 검사 완료
- 실기기 지도 검색·필터 검증 보류

## 지도 검색

- [ ] 카페명으로 지도 마커를 검색할 수 있다.
- [ ] 도로명 주소와 지번 주소로 검색할 수 있다.
- [ ] 대표 테마명으로 검색할 수 있다.
- [ ] 카페 테마명과 세부 태그명으로 검색할 수 있다.
- [ ] 추천 메모 내용으로 검색할 수 있다.
- [ ] 검색어 지우기 버튼이 작동한다.
- [ ] 한글 검색어의 앞뒤 공백을 무시한다.

## 관계 필터

- [ ] 전체 필터가 모든 좌표 카페를 표시한다.
- [ ] 가보고 싶어요 필터가 작동한다.
- [ ] 좋아하는 장소 필터가 작동한다.
- [ ] 방문했어요 필터가 작동한다.
- [ ] 검색어와 관계 필터를 함께 적용할 수 있다.

## 대표 테마 필터

- [ ] 저장된 카페에 사용된 대표 테마만 표시된다.
- [ ] 대표 테마 필터가 작동한다.
- [ ] 검색어·관계·대표 테마를 함께 적용할 수 있다.
- [ ] 필터 개수가 표시된다.
- [ ] 필터 영역을 접고 펼칠 수 있다.

## 지도 결과

- [ ] 검색·필터 결과 수가 표시된다.
- [ ] 좌표가 없는 결과 수가 표시된다.
- [ ] 조건 변경 후 선택 마커가 유효한 카페로 갱신된다.
- [ ] 조건 변경 후 결과 마커가 자동으로 화면에 맞춰진다.
- [ ] 전체 보기 버튼이 현재 조건의 마커만 맞춘다.
- [ ] 결과가 없을 때 안내 카드가 나타난다.
- [ ] 초기화 버튼이 검색과 필터를 모두 되돌린다.

## 기존 V37 기능

- [ ] 지도 배경이 정상적으로 표시된다.
- [ ] 마커를 누르면 하단 카페 카드가 표시된다.
- [ ] 상세 보기·수정 버튼이 작동한다.
- [ ] 목록 버튼과 뒤로가기 버튼이 작동한다.
- [ ] 좌표가 있는 카페가 전혀 없을 때 기존 빈 화면이 유지된다.
- [ ] 오프라인에서도 로컬 저장 카페를 검색할 수 있다.
