# ROOT 저장 카페 지도 실기기 테스트

현재 상태:

- V37 정적 검사 완료
- TypeScript 검사 완료
- 실기기 지도 검증 보류

## 지도 진입

- [ ] 저장 카페 목록의 지도 버튼이 작동한다.
- [ ] 지도 화면의 뒤로가기 버튼이 작동한다.
- [ ] 지도 화면의 목록 버튼이 작동한다.
- [ ] 카페 추가 버튼으로 이동할 수 있다.

## 마커와 지도 범위

- [ ] 좌표가 있는 저장 카페가 마커로 표시된다.
- [ ] 좌표가 없는 카페 수가 별도로 표시된다.
- [ ] 여러 카페가 있을 때 모든 마커가 화면에 맞춰진다.
- [ ] 한 곳만 있을 때 해당 카페를 중심으로 표시한다.
- [ ] 전체 보기 버튼이 모든 마커를 다시 보여준다.
- [ ] 지도 확대·축소·이동이 작동한다.

## 선택 카페 카드

- [ ] 마커를 누르면 해당 카페 카드가 표시된다.
- [ ] 카페명과 주소가 표시된다.
- [ ] 가보고 싶어요·좋아하는 장소·방문했어요 상태가 표시된다.
- [ ] 대표 테마가 표시된다.
- [ ] 상세 보기·수정 버튼이 올바른 카페로 이동한다.

## 빈 상태와 오류

- [ ] 좌표가 있는 카페가 없으면 안내 카드가 표시된다.
- [ ] 로딩 중 진행 표시가 나타난다.
- [ ] 불러오기 오류 시 다시 불러오기 버튼이 나타난다.
- [ ] 오프라인에서도 로컬에 저장된 카페 지도가 열린다.

## 지도 네이티브 확인

- [ ] Android 지도 배경이 회색이나 빈 화면으로 나오지 않는다.
- [ ] Android 기본 마커가 잘리지 않는다.
- [ ] 화면을 나갔다 돌아와도 지도와 마커가 유지된다.
- [ ] 앱을 백그라운드로 보냈다가 돌아와도 종료되지 않는다.
