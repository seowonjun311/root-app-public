# ROOT V48 개인 맞춤 카페 추천 런타임 체크리스트

## 목표

V47에서 분석한 방문 목적·동행·재방문 의향과 저장 카페의
대표 테마·카페 테마·키워드를 조합해 설명 가능한 개인 맞춤 추천이 동작하는지 확인합니다.

## 1. 추천 화면 진입

- [ ] V47 카페 방문 인사이트 상단의 `ROOT 맞춤 추천` 카드를 누르면 추천 화면이 열린다.
- [ ] 추천 화면의 뒤로 가기가 정상 작동한다.
- [ ] 저장 카페와 방문 기록을 불러오는 동안 로딩 상태가 표시된다.
- [ ] 네트워크 오류가 있어도 기존 로컬 저장 데이터를 사용한 로딩 흐름이 유지된다.

## 2. 추천 프로필

- [ ] 추천 정확도가 `시작 단계 / 성장 중 / 높음` 중 하나로 표시된다.
- [ ] 방문 기록 횟수가 표시된다.
- [ ] V46 상세 기록 횟수가 표시된다.
- [ ] 주된 방문 목적이 있으면 추천 헤드라인에 반영된다.
- [ ] 주된 동행 유형이 있으면 설명에 반영된다.
- [ ] 상세 방문 기록이 늘어나면 추천 정확도 단계가 올라간다.

## 3. 전체 추천

- [ ] 저장한 카페가 추천 점수 높은 순으로 표시된다.
- [ ] 각 카페에 1~99 범위 추천 점수가 표시된다.
- [ ] 추천 이유가 최대 3개까지 표시된다.
- [ ] 대표 키워드가 있는 카페는 키워드 칩이 표시된다.
- [ ] 방문한 카페는 방문 횟수와 평균 별점이 표시된다.
- [ ] 아직 방문하지 않은 카페는 `아직 방문 기록 없음`이 표시된다.
- [ ] 추천 카드를 누르면 해당 카페 상세 화면으로 이동한다.

## 4. 아직 안 간 곳

- [ ] `아직 안 간 곳` 필터에서는 방문 기록이 0회인 저장 카페만 표시된다.
- [ ] 방문하지 않은 카페에 추가 추천 가중치가 적용된다.
- [ ] 모든 저장 카페를 방문했다면 빈 상태 안내가 표시된다.

## 5. 공부·작업 추천

- [ ] 공부 대표 테마가 있는 카페가 우선된다.
- [ ] 공부하기 좋은 카페 테마가 반영된다.
- [ ] 노트북하기 좋은 카페 테마가 반영된다.
- [ ] 조용한 카페 테마가 반영된다.
- [ ] 공부하기 좋음, 노트북 작업, 콘센트, 와이파이, 장시간 이용 등 키워드가 점수에 반영된다.
- [ ] V46에서 공부/업무 목적을 자주 기록할수록 관련 추천이 강화된다.

## 6. 데이트 추천

- [ ] 데이트 대표 테마가 있는 카페가 우선된다.
- [ ] 데이트 카페, 감성 카페, 뷰 좋은 카페 테마가 반영된다.
- [ ] 데이트, 감성, 사진, 채광, 야경, 노을 등의 키워드가 점수에 반영된다.
- [ ] V46에서 데이트 목적이나 연인 동행 기록이 많을수록 관련 추천이 강화된다.

## 7. 혼자 추천

- [ ] 혼자 가기 좋음 키워드가 반영된다.
- [ ] 1인석, 조용함, 독서, 노트북 사용 편의가 반영된다.
- [ ] V46에서 혼자 방문 기록이 많을수록 관련 추천이 강화된다.

## 8. 다시 가기 추천

- [ ] `다시 가기` 필터에서는 `또 가고 싶어요` 기록이 있는 카페만 표시된다.
- [ ] 재방문 의향 `yes` 횟수가 많을수록 점수가 올라간다.
- [ ] 높은 평균 별점도 추천 점수에 반영된다.
- [ ] `다시 가진 않을래요` 기록은 추천 점수에 감점으로 반영된다.

## 9. 설명 가능한 추천

- [ ] 추천 이유에 현재 선택한 상황 조건이 표시될 수 있다.
- [ ] 가장 많이 기록한 방문 목적과의 일치가 이유로 표시될 수 있다.
- [ ] 선호 키워드 일치가 이유로 표시될 수 있다.
- [ ] 선호 카페 테마 일치가 이유로 표시될 수 있다.
- [ ] 아직 안 간 카페라는 이유가 표시될 수 있다.
- [ ] 재방문 의향이 있는 카페라는 이유가 표시될 수 있다.

## 10. 회귀 테스트

- [ ] V42 방문 기록이 정상이다.
- [ ] V43 기본 인사이트가 정상이다.
- [ ] V44 챌린지/마일스톤이 정상이다.
- [ ] V45 방문 캘린더가 정상이다.
- [ ] V46 방문 상세 저장이 정상이다.
- [ ] V47 카페 취향 통계가 정상이다.
- [ ] 저장 카페 목록, 지도, 폴더, 상세 수정 기능이 정상이다.

## 완료 기준

핵심 항목이 실기기에서 통과하면 V48 런타임 검증 완료로 처리합니다.
