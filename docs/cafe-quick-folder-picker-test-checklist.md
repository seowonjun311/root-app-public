# ROOT 카페별 빠른 폴더 분류 실기기 테스트

현재 상태:

- V41 정적 검사 완료
- TypeScript 검사 완료
- 실기기 빠른 폴더 분류 검증 보류

## 저장 카페 목록

- [ ] 각 카페 카드에 폴더에 담기 버튼이 표시된다.
- [ ] 폴더에 담기 버튼이 해당 카페의 폴더 선택 화면을 연다.
- [ ] 기존 상세 보기·수정 버튼이 그대로 작동한다.
- [ ] 기존 목록 검색·필터·정렬이 유지된다.
- [ ] 상단 폴더·지도·카페 추가 버튼이 유지된다.

## 카페 상세 화면

- [ ] 조회 상태에서 나만의 폴더 버튼이 표시된다.
- [ ] 수정 상태에서는 폴더 버튼이 숨겨진다.
- [ ] 버튼을 누르면 현재 카페의 폴더 선택 화면이 열린다.
- [ ] 기존 카페 정보 수정과 저장이 유지된다.

## 폴더 선택 화면

- [ ] 선택한 카페명과 주소가 표시된다.
- [ ] 현재 담긴 폴더 수가 표시된다.
- [ ] 폴더 이름을 검색할 수 있다.
- [ ] 폴더별 전체 카페 수가 표시된다.
- [ ] 폴더를 눌러 해당 폴더 전체 화면을 열 수 있다.
- [ ] 담기 버튼으로 폴더에 추가할 수 있다.
- [ ] 담김 버튼으로 폴더에서 뺄 수 있다.
- [ ] 한 카페를 여러 폴더에 동시에 담을 수 있다.
- [ ] 저장 중 중복 터치가 차단된다.

## 빠른 폴더 생성

- [ ] 새 폴더 버튼이 작동한다.
- [ ] 아이콘 10종을 선택할 수 있다.
- [ ] 폴더 이름 최대 글자 수가 적용된다.
- [ ] 빈 이름 저장이 차단된다.
- [ ] 중복 이름 안내가 표시된다.
- [ ] 새 폴더를 만들면 현재 카페가 자동으로 담긴다.
- [ ] 폴더 최대 개수에 도달하면 안내가 표시된다.

## 빈 상태와 오류

- [ ] 폴더가 없을 때 첫 폴더 만들기 안내가 표시된다.
- [ ] 검색 결과가 없을 때 안내 카드가 표시된다.
- [ ] 저장 카페가 삭제됐을 때 오류 안내가 표시된다.
- [ ] 불러오기 실패 시 다시 불러오기 버튼이 작동한다.
- [ ] 폴더 변경 실패 시 오류 안내가 표시된다.

## 동기화와 회귀 테스트

- [ ] 게스트 상태에서도 폴더 분류가 로컬에 저장된다.
- [ ] 로그인 상태에서 기존 V40 클라우드 동기화가 유지된다.
- [ ] 앱을 종료한 뒤 다시 열어도 분류가 유지된다.
- [ ] 다른 기기에서 폴더 분류가 동기화된다.
- [ ] V37~V39 지도 기능이 영향을 받지 않는다.
- [ ] 새 네이티브 빌드 없이 기존 개발 빌드에서 화면을 열 수 있다.
