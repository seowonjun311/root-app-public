# ROOT V49 개인 맞춤 추천 피드백 + 학습 루프 런타임 체크리스트

## 목표

V48 개인 맞춤 카페 추천에 사용자의 직접 피드백을 추가하고,
피드백이 현재 카페뿐 아니라 비슷한 대표 테마·카페 테마·키워드의 추천 점수에도
즉시 반영되는지 확인합니다.

## 1. 추천 화면 기본 진입

- [ ] V48 `ROOT 맞춤 추천` 화면이 정상적으로 열린다.
- [ ] 저장 카페와 방문 기록이 정상적으로 로드된다.
- [ ] V49 추천 피드백 데이터도 함께 로드된다.
- [ ] 기존 전체 추천 / 아직 안 간 곳 / 공부·작업 / 데이트 / 혼자 / 다시 가기 필터가 정상이다.

## 2. 피드백 버튼

각 추천 카드에서 아래 버튼이 표시되는지 확인합니다.

- [ ] 관심 있어요
- [ ] 나중에 가볼래요
- [ ] 관심 없어요
- [ ] 선택한 버튼은 선택 상태로 표시된다.
- [ ] 다른 버튼을 누르면 기존 반응 대신 새 반응이 저장된다.
- [ ] 같은 버튼을 다시 누르면 피드백이 해제된다.
- [ ] 피드백 저장 중 중복 입력이 방지된다.
- [ ] 피드백 버튼을 눌러도 카페 상세 화면으로 잘못 이동하지 않는다.

## 3. 관심 있어요 학습

- [ ] `관심 있어요`를 누르면 해당 카페 추천 점수가 즉시 올라간다.
- [ ] 해당 카페와 같은 대표 테마의 다른 카페에도 긍정 가중치가 반영된다.
- [ ] 같은 카페 테마를 가진 추천에도 긍정 가중치가 반영된다.
- [ ] 같은 대표 키워드/키워드를 가진 추천에도 긍정 가중치가 반영된다.
- [ ] 추천 이유에 피드백 반영 문구가 표시될 수 있다.

## 4. 나중에 가볼래요 학습

- [ ] `나중에 가볼래요`를 누르면 해당 카페가 추천에서 더 잘 보이도록 점수가 올라간다.
- [ ] 비슷한 특성의 카페에도 완만한 긍정 가중치가 반영된다.
- [ ] 앱을 다시 열어도 선택 상태가 유지된다.

## 5. 관심 없어요 학습

- [ ] `관심 없어요`를 누르면 해당 카페 점수가 크게 낮아진다.
- [ ] 비슷한 대표 테마·카페 테마·키워드의 추천도 완만하게 낮아진다.
- [ ] 추천 이유에 관심 없음 피드백이 반영되었다는 설명이 표시될 수 있다.
- [ ] 다른 긍정 방문 기록이 충분히 많으면 모든 유사 카페가 무조건 사라지지 않는다.

## 6. 추천 학습 요약

- [ ] 화면 상단에 `추천 학습 N개`가 표시된다.
- [ ] 관심 있어요 개수가 표시된다.
- [ ] 나중에 가볼래요 개수가 표시된다.
- [ ] 관심 없음 개수가 표시된다.
- [ ] 피드백을 해제하면 요약 개수가 즉시 감소한다.
- [ ] 추천 정확도 단계가 방문 상세 기록 + 추천 피드백을 함께 반영한다.

## 7. 저장 및 재실행

- [ ] 게스트 상태에서 피드백을 저장할 수 있다.
- [ ] 앱을 완전히 종료 후 다시 실행해도 피드백이 유지된다.
- [ ] 로그인 상태에서도 피드백을 저장할 수 있다.
- [ ] 로그인 사용자의 피드백이 Firestore 사용자 문서에 동기화된다.
- [ ] 다른 기기/새 세션에서 동일 계정 로그인 후 피드백이 병합된다.
- [ ] 게스트에서 남긴 피드백이 로그인 후 사용자 데이터로 이전된다.
- [ ] 피드백 해제 상태도 다른 기기에 정상 병합된다.

## 8. 실제 방문과 학습 루프

추천 → 피드백 → 실제 방문 → 방문 평가까지 이어지는지 확인합니다.

- [ ] 추천 카페에 `관심 있어요` 또는 `나중에 가볼래요`를 남긴다.
- [ ] 해당 카페를 실제 방문한 뒤 V46 방문 상세를 작성한다.
- [ ] 별점 4~5점과 `또 가고 싶어요`를 남기면 기존 V48 방문 기반 가중치가 함께 적용된다.
- [ ] 낮은 별점 또는 `다시 가진 않을래요`를 남기면 방문 기반 감점도 함께 적용된다.
- [ ] 추천 피드백과 실제 방문 결과가 동시에 있을 때 추천 점수가 오류 없이 계산된다.

## 9. 추천 점수 안전성

- [ ] 추천 점수는 항상 1~99 사이로 표시된다.
- [ ] 관심 없음 피드백을 여러 카페에 남겨도 음수 점수가 화면에 표시되지 않는다.
- [ ] 피드백이 전혀 없는 기존 사용자는 V48과 유사한 추천 결과를 받는다.
- [ ] 과거 방문 기록만 있는 사용자도 오류 없이 추천된다.
- [ ] 저장 카페만 있고 방문 기록이 없는 사용자도 추천된다.
