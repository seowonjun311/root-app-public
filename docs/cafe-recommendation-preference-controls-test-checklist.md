# ROOT V50 사용자 취향 설정 + 추천 가중치 직접 조절 런타임 체크리스트

## 목표

V49의 방문 기록·추천 피드백 자동 학습을 유지하면서,
사용자가 직접 카페 취향 우선순위를 -2~+2로 조절하고
자동 학습 강도까지 선택할 수 있는지 확인합니다.

## 1. V50 취향 설정 화면 진입

- [ ] `ROOT 맞춤 카페 추천` 화면에 `취향 설정` 카드가 표시된다.
- [ ] 취향 설정 카드를 누르면 V50 취향 설정 화면이 열린다.
- [ ] 뒤로 가기를 누르면 추천 화면으로 돌아온다.
- [ ] 추천 화면으로 돌아오면 변경된 취향이 즉시 추천 순위에 반영된다.

## 2. 직접 추천 가중치 8개

다음 8개 항목이 모두 표시되는지 확인합니다.

- [ ] 공부·작업
- [ ] 조용·휴식
- [ ] 데이트·감성
- [ ] 커피·디저트
- [ ] 넓은 공간
- [ ] 뷰·사진
- [ ] 혼자 가기
- [ ] 심야·24시간

각 항목에서 아래 5단계가 정상적으로 선택되는지 확인합니다.

- [ ] -- : 피하고 싶어요
- [ ] - : 덜 중요
- [ ] 0 : 기본
- [ ] + : 중요
- [ ] ++ : 매우 중요

## 3. 직접 가중치 추천 반영

- [ ] 공부·작업을 `++`로 하면 공부/노트북/와이파이/콘센트 관련 카페가 상승한다.
- [ ] 조용·휴식을 `++`로 하면 조용한 카페, 독서, 휴식 관련 카페가 상승한다.
- [ ] 데이트·감성을 `++`로 하면 데이트/감성/뷰 관련 카페가 상승한다.
- [ ] 커피·디저트를 `++`로 하면 베이커리/케이크/커피/브런치 관련 카페가 상승한다.
- [ ] 넓은 공간을 `++`로 하면 대형 카페/많은 좌석/넓은 좌석 간격 관련 카페가 상승한다.
- [ ] 뷰·사진을 `++`로 하면 뷰/사진/야경/노을 관련 카페가 상승한다.
- [ ] 혼자 가기를 `++`로 하면 1인석/혼자 가기/조용한 카페가 상승한다.
- [ ] 심야·24시간을 `++`로 하면 심야/24시간/늦게까지 영업 관련 카페가 상승한다.
- [ ] 동일 항목을 `--`로 설정하면 반대 방향으로 추천 점수가 낮아진다.
- [ ] 추천 점수는 항상 1~99 범위를 유지한다.

## 4. 추천 이유

- [ ] 직접 설정과 일치하는 카페에 `직접 설정:` 추천 이유가 표시될 수 있다.
- [ ] `++` 설정은 `매우 중요하게 반영` 문구로 설명될 수 있다.
- [ ] `+` 설정은 `중요하게 반영` 문구로 설명될 수 있다.
- [ ] `-` 설정은 `덜 선호` 문구로 설명될 수 있다.
- [ ] `--` 설정은 `피하고 싶다는 취향` 문구로 설명될 수 있다.
- [ ] 기존 V48/V49 추천 이유도 함께 유지된다.

## 5. 자동 학습 강도

- [ ] 낮게
- [ ] 균형
- [ ] 높게
- [ ] 기본값은 `균형`이다.
- [ ] `낮게`에서는 방문 기록/유사 피드백 기반 변화가 완만해진다.
- [ ] `높게`에서는 방문 기록/유사 피드백 기반 변화가 더 크게 반영된다.
- [ ] V49에서 특정 카페에 직접 남긴 `관심 있어요/나중에/관심 없음` 자체의 직접 효과는 유지된다.

## 6. 추천 화면 요약

- [ ] `취향 설정 N개`가 표시된다.
- [ ] 중요하게 설정한 항목 개수가 표시된다.
- [ ] 덜 선호하도록 설정한 항목 개수가 표시된다.
- [ ] 현재 자동 학습 강도가 표시된다.
- [ ] 추천 프로필 설명에 직접 설정 개수와 자동 학습 강도가 반영된다.

## 7. 기본값 초기화

- [ ] `기본값으로 초기화` 버튼이 표시된다.
- [ ] 초기화 전 확인 창이 표시된다.
- [ ] 초기화하면 8개 직접 가중치가 모두 0이 된다.
- [ ] 자동 학습 강도가 `균형`으로 돌아온다.
- [ ] 추천 화면으로 돌아오면 초기화된 추천 순위가 적용된다.

## 8. 로컬/클라우드 동기화

- [ ] 게스트 상태에서 취향 설정을 저장할 수 있다.
- [ ] 앱 재실행 후 취향 설정이 유지된다.
- [ ] 로그인 상태에서 취향 설정을 저장할 수 있다.
- [ ] Firestore `savedCafeRecommendationPreferenceData`에 동기화된다.
- [ ] 다른 기기/새 세션에서 같은 계정 로그인 후 설정이 복원된다.
- [ ] 게스트에서 만든 사용자 취향 설정이 로그인 후 계정 데이터로 이어진다.
- [ ] 서버에 취향 데이터가 없는 첫 동기화에서 로컬 설정이 기본값으로 덮어써지지 않는다.

## 9. V49 학습과 함께 동작

- [ ] `관심 있어요`를 남긴 뒤 직접 설정을 바꿔도 두 신호가 모두 반영된다.
- [ ] `관심 없어요` 직접 감점이 V50 때문에 사라지지 않는다.
- [ ] 방문 별점/재방문 의향과 V50 직접 설정이 함께 계산된다.
- [ ] 직접 설정이 모두 0이면 V49와 유사한 추천 결과를 유지한다.
