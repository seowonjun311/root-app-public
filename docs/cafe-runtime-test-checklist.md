# ROOT 카페 기능 실기기 테스트

현재 상태:

- 정적 검사 완료
- TypeScript 검사 완료
- GitHub 백업 완료
- 실기기 실행 검증 보류

## 1. 카카오 검색

- [ ] 카페 저장 화면이 정상적으로 열린다.
- [ ] 검색창에 `성수 카페`를 입력할 수 있다.
- [ ] 검색 버튼을 누르면 결과가 표시된다.
- [ ] 카페 이름이 정상적으로 표시된다.
- [ ] 도로명 주소 또는 지번 주소가 표시된다.
- [ ] 검색 결과를 선택하면 저장 화면에 반영된다.
- [ ] 검색 결과가 없을 때 안내 문구가 표시된다.
- [ ] 네트워크 오류가 발생해도 앱이 종료되지 않는다.

## 2. 카페 저장

- [ ] 관계를 선택할 수 있다.
- [ ] 대표 테마를 선택할 수 있다.
- [ ] 추가 테마를 선택할 수 있다.
- [ ] 계절을 여러 개 선택할 수 있다.
- [ ] 카페 세부 키워드를 선택할 수 있다.
- [ ] 추천 메모를 입력할 수 있다.
- [ ] 저장 버튼을 연속으로 눌러도 중복 저장되지 않는다.
- [ ] 저장 중에는 진행 표시가 나타난다.
- [ ] 저장 완료 후 ROOT 완료창이 나타난다.
- [ ] 저장 목록 보기 버튼이 작동한다.
- [ ] 탐험으로 돌아가기 버튼이 작동한다.

## 3. 저장된 카페 목록

- [ ] 저장한 카페가 목록에 바로 표시된다.
- [ ] 앱을 재실행해도 저장한 카페가 유지된다.
- [ ] 카페명과 주소가 정상적으로 표시된다.
- [ ] 대표 테마와 태그가 정상적으로 표시된다.
- [ ] 저장한 관계가 정상적으로 표시된다.
- [ ] 목록이 비었을 때 빈 화면 안내가 표시된다.

## 4. 삭제

- [ ] 삭제 버튼을 누르면 ROOT 삭제 카드가 나타난다.
- [ ] Android 기본 Alert 창은 나타나지 않는다.
- [ ] 취소 버튼을 누르면 삭제되지 않는다.
- [ ] 카드 바깥을 누르면 안전하게 닫힌다.
- [ ] 삭제 확인을 누르면 진행 표시가 나타난다.
- [ ] 삭제 버튼을 연속으로 눌러도 한 번만 처리된다.
- [ ] 삭제 완료 후 목록에서 즉시 사라진다.
- [ ] 앱을 재실행해도 삭제된 카페가 다시 나타나지 않는다.

## 5. 보안

- [ ] `.env` 파일이 Git에 포함되지 않는다.
- [ ] 카카오 REST API 키가 화면이나 로그에 출력되지 않는다.
- [ ] `.env.example`에는 실제 인증키가 들어 있지 않다.
- [ ] GitHub 저장소에서 실제 인증키가 검색되지 않는다.
