# ROOT 저장 카페 검색·필터·정렬 실기기 테스트

현재 상태:

- V36 정적 검사 완료
- TypeScript 검사 완료
- 실기기 실행 검증 보류

## 검색

- [ ] 카페명으로 검색할 수 있다.
- [ ] 주소로 검색할 수 있다.
- [ ] 대표 테마명과 카페 테마명으로 검색할 수 있다.
- [ ] 계절명과 태그명으로 검색할 수 있다.
- [ ] 추천 메모 내용으로 검색할 수 있다.
- [ ] 검색어 지우기 버튼이 작동한다.

## 필터

- [ ] 관계 필터가 작동한다.
- [ ] 대표 테마 필터가 작동한다.
- [ ] 카페 테마 필터가 작동한다.
- [ ] 연중·봄·여름·가을·겨울 필터가 작동한다.
- [ ] 여러 조건을 함께 적용할 수 있다.
- [ ] 적용된 필터 개수가 표시된다.
- [ ] 초기화 버튼이 모든 조건을 되돌린다.

## 정렬

- [ ] 최근 수정 순이 기본값이다.
- [ ] 오래된 순이 작동한다.
- [ ] 이름순이 작동한다.

## 기존 기능

- [ ] 동기화 상태 카드가 유지된다.
- [ ] 다시 시도 버튼이 유지된다.
- [ ] 상세 보기·수정이 작동한다.
- [ ] ROOT 삭제 확인창이 유지된다.
- [ ] 삭제 후 결과 수가 갱신된다.
