# ROOT 카페 동기화 상태 표시 및 수동 재시도 테스트

현재 상태:

- V35 정적 구현 완료
- 실기기 실행 검증 보류

## 1. 로그인하지 않은 상태

- [ ] 저장한 카페 화면에 `이 기기에 저장됨`이 표시된다.
- [ ] 게스트 상태에서는 다시 시도 버튼이 나타나지 않는다.
- [ ] 카페 저장·수정·삭제가 로컬에서 정상 작동한다.

## 2. 정상 동기화

- [ ] 저장한 카페 화면 진입 시 `카페 동기화 중`이 표시된다.
- [ ] 동기화 성공 후 `동기화 완료`가 표시된다.
- [ ] 마지막 동기화 시간이 표시된다.
- [ ] 서버에서 복원된 카페가 목록에 반영된다.
- [ ] 저장 직후 동기화 상태가 갱신된다.
- [ ] 수정 직후 동기화 상태가 갱신된다.
- [ ] 삭제 직후 동기화 상태가 갱신된다.

## 3. 오프라인 상태

- [ ] 인터넷이 없는 상태에서도 카페가 로컬에 저장된다.
- [ ] 동기화 실패 후 `오프라인 저장됨`이 표시된다.
- [ ] `다시 시도` 버튼이 나타난다.
- [ ] 다시 시도 버튼을 여러 번 눌러도 중복 요청되지 않는다.
- [ ] 인터넷 연결 후 다시 시도하면 `동기화 완료`로 변경된다.
- [ ] 오프라인에서 삭제한 카페가 다시 나타나지 않는다.

## 4. 일반 오류 상태

- [ ] 네트워크 외 오류에서 `동기화 확인 필요`가 표시된다.
- [ ] 오류가 발생해도 저장 카페 목록은 사라지지 않는다.
- [ ] 다시 시도 후 성공하면 오류 상태가 해제된다.

## 5. 화면 전환

- [ ] 상세 화면에서 수정 후 목록으로 돌아오면 최신 정보가 보인다.
- [ ] 다른 탭으로 이동했다 돌아와도 상태 카드가 정상 표시된다.
- [ ] 앱 재실행 후 목록을 불러오며 동기화 상태가 갱신된다.
