# ROOT V51 카페 시스템 통합 런타임 검증·안정화 체크리스트

## 목표

V42~V50에서 누적된 저장 카페, 방문 기록, 폴더, 인사이트, 캘린더,
추천 피드백, 추천 취향 설정을 하나의 흐름으로 검증합니다.

V51 진단은 비파괴 방식입니다.
빠른 점검은 로컬 데이터를 읽기만 하고,
동기화 포함 점검은 기존 Firestore 병합 동기화만 실행합니다.

## 1. V51 진단 화면 진입

- [ ] 저장 카페 화면 상단 동기화 카드 아래에 `카페 시스템 통합 점검` 카드가 보인다.
- [ ] 카드를 누르면 V51 진단 화면이 열린다.
- [ ] 진단 화면을 처음 열면 빠른 점검이 자동 실행된다.
- [ ] 뒤로 가기가 정상 작동한다.

## 2. 빠른 로컬 점검

- [ ] `V40~V50 로컬 데이터 로드`가 PASS다.
- [ ] 저장 카페 식별자 검사가 PASS다.
- [ ] 카페 추천 메타데이터 검사가 PASS다.
- [ ] 방문 기록 식별자 검사가 PASS다.
- [ ] 방문 기록 날짜/별점 검사가 PASS다.
- [ ] 폴더 식별자·이름 검사가 PASS다.
- [ ] 폴더 ↔ 카페 연결에 FAIL이 없다.
- [ ] 추천 피드백 데이터에 FAIL이 없다.
- [ ] 사용자 직접 취향 설정이 PASS다.
- [ ] 추천 엔진 6개 모드가 PASS다.
- [ ] 추천 결과 결정성이 PASS다.

## 3. 데이터 참조 경고 해석

다음 항목은 WARN/`확인`으로 표시될 수 있으며 자동 삭제하지 않습니다.

- [ ] 저장 목록에서 삭제한 카페의 과거 방문 기록이 있으면 방문 ↔ 저장 카페 연결이 경고가 될 수 있다.
- [ ] 삭제한 카페에 남긴 과거 추천 피드백이 있으면 피드백 ↔ 저장 카페 연결이 경고가 될 수 있다.
- [ ] 삭제 직후 동기화 중인 폴더 연결이 있으면 폴더 ↔ 카페 연결이 경고가 될 수 있다.
- [ ] 경고가 실제 오류인지 보존 의도인지 확인한 뒤 수정 여부를 결정한다.

## 4. 추천 엔진 자동 검증

V51은 아래 6개 모드를 같은 입력으로 두 번 계산합니다.

- [ ] 전체 추천
- [ ] 아직 안 간 곳
- [ ] 공부·작업
- [ ] 데이트
- [ ] 혼자
- [ ] 다시 가기

자동 검사 기준:

- [ ] 모든 추천 점수가 1~99 범위다.
- [ ] 추천 목록에 동일 placeId가 중복되지 않는다.
- [ ] 추천 카페가 현재 저장 카페 데이터에 존재한다.
- [ ] `아직 안 간 곳` 추천에는 방문 0회 카페만 있다.
- [ ] `다시 가기` 추천에는 `또 가고 싶어요` 기록이 있는 카페만 있다.
- [ ] 동일 입력으로 두 번 계산한 추천 순서와 점수가 동일하다.

## 5. 동기화 포함 점검

로그인 상태에서 진행합니다.

- [ ] `동기화 포함` 버튼을 누르면 확인 창이 먼저 표시된다.
- [ ] 저장 카페 Firestore 병합 동기화 PASS
- [ ] 방문 기록 Firestore 병합 동기화 PASS
- [ ] 폴더 Firestore 병합 동기화 PASS
- [ ] V49 추천 피드백 Firestore 병합 동기화 PASS
- [ ] V50 추천 취향 Firestore 병합 동기화 PASS
- [ ] 동기화 후 로컬 정합성 검사가 다시 PASS한다.
- [ ] 게스트 상태에서는 클라우드 검사를 건너뛰었다는 정보가 표시된다.

## 6. V42 방문 기록 수동 확인

- [ ] 진단 화면의 `방문 기록` 버튼으로 이동한다.
- [ ] 방문 추가가 정상이다.
- [ ] 같은 카페의 여러 방문 기록이 표시된다.
- [ ] 방문 수정이 정상이다.
- [ ] 방문 삭제가 정상이다.
- [ ] 카페별 타임라인 이동이 정상이다.

## 7. V45 캘린더 수동 확인

- [ ] 진단 화면의 `방문 캘린더` 버튼으로 이동한다.
- [ ] 이전 달/다음 달 이동이 정상이다.
- [ ] 방문한 날짜의 집계가 맞다.
- [ ] 날짜 선택 후 방문 목록이 맞다.
- [ ] 방문 카드를 누르면 V46 방문 상세로 이동한다.

## 8. V43/V47 인사이트 수동 확인

- [ ] 진단 화면의 `방문 인사이트` 버튼으로 이동한다.
- [ ] 총 방문·방문 카페·평균 별점이 방문 기록과 맞다.
- [ ] 방문 목적 비율이 맞다.
- [ ] 동행 비율이 맞다.
- [ ] 재방문 의향 비율이 맞다.
- [ ] 최근 30일 패턴이 맞다.
- [ ] 상황별 자주 간 카페가 맞다.

## 9. V44 챌린지 수동 확인

- [ ] 진단 화면의 `방문 챌린지` 버튼으로 이동한다.
- [ ] 챌린지 진행률이 방문 데이터와 맞다.
- [ ] 마일스톤 표시가 정상이다.
- [ ] 인사이트/캘린더로 돌아가는 흐름이 정상이다.

## 10. V48/V49 추천 수동 확인

- [ ] 진단 화면의 `맞춤 추천` 버튼으로 이동한다.
- [ ] 6개 추천 필터가 모두 동작한다.
- [ ] 추천 점수는 1~99 범위다.
- [ ] 추천 이유가 표시된다.
- [ ] `관심 있어요`를 누르면 즉시 재계산된다.
- [ ] `나중에 가볼래요`를 누르면 즉시 재계산된다.
- [ ] `관심 없어요`를 누르면 즉시 재계산된다.
- [ ] 같은 피드백을 다시 누르면 해제된다.
- [ ] 추천 카드를 누르면 카페 상세로 이동한다.

## 11. V50 취향 설정 수동 확인

- [ ] 진단 화면의 `취향 설정` 버튼으로 이동한다.
- [ ] 8개 가중치를 -2~-+2 범위로 바꿀 수 있다.
- [ ] 자동 학습 강도를 낮게/균형/높게 변경할 수 있다.
- [ ] 추천 화면으로 돌아오면 순위가 즉시 반영된다.
- [ ] 기본값 초기화가 정상이다.

## 12. 앱 재시작 검증

- [ ] 추천 피드백을 하나 남긴다.
- [ ] 직접 취향 설정을 하나 변경한다.
- [ ] 앱을 완전히 종료한다.
- [ ] 앱을 다시 실행한다.
- [ ] 추천 피드백이 유지된다.
- [ ] 직접 취향 설정이 유지된다.
- [ ] V51 빠른 점검을 다시 실행해 FAIL이 없는지 확인한다.

## 13. 최종 V51 완료 기준

다음 조건을 모두 만족하면 V52 진행 가능 상태입니다.

- [ ] 자동 진단 `FAIL = 0`
- [ ] 동기화 포함 점검에서 치명적 오류 없음
- [ ] V42~V50 주요 화면 모두 열림
- [ ] 방문 생성/수정/삭제 정상
- [ ] 캘린더 → 방문 상세 연결 정상
- [ ] 인사이트 수치 정상
- [ ] 추천 피드백 즉시 반영 정상
- [ ] 직접 취향 설정 즉시 반영 정상
- [ ] 앱 재실행 후 데이터 유지
- [ ] 로그인 후 Firestore 동기화 정상

FAIL이 하나라도 있으면 V52로 넘어가기 전에 해당 로그와 화면을 기준으로
V51 안정화 패치를 먼저 진행합니다.
