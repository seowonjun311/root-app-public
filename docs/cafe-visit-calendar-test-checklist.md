# ROOT V45 카페 방문 캘린더·월별 기록 실기기 테스트

## 목적

V42 방문 기록을 월별 캘린더로 확인하고 V43 인사이트·V44 도전 화면과 함께 정상 동작하는지 확인합니다.

## 1. 진입

- 저장 카페 → 방문 기록 → 통계로 이동합니다.
- 카페 방문 인사이트 상단의 `방문 캘린더` 카드를 누릅니다.
- `카페 방문 캘린더` 화면이 열리는지 확인합니다.

## 2. 월 이동

- 이전 달 버튼을 눌렀을 때 한 달씩 이동하는지 확인합니다.
- 다음 달 버튼을 눌렀을 때 한 달씩 이동하는지 확인합니다.
- 현재 달이 아닐 때 `이번 달` 버튼이 나타나는지 확인합니다.
- `이번 달` 버튼을 누르면 현재 월과 오늘 날짜 선택 상태로 돌아오는지 확인합니다.

## 3. 월간 요약

- `이번 달 방문`이 선택된 월의 전체 방문 횟수와 일치하는지 확인합니다.
- `방문한 날`이 실제 방문 기록이 있는 날짜 수와 일치하는지 확인합니다.
- `가장 바쁜 날`이 해당 월에서 방문 기록이 가장 많은 날짜의 횟수와 일치하는지 확인합니다.
- `최장 연속 방문`이 전체 방문 날짜를 기준으로 연속된 날짜 수를 올바르게 계산하는지 확인합니다.

## 4. 캘린더

- 방문 기록이 있는 날짜에 방문 횟수 배지가 보이는지 확인합니다.
- 하루에 방문 기록이 2개 이상이면 배지 숫자가 합산되는지 확인합니다.
- 오늘 날짜의 글씨가 강조되는지 확인합니다.
- 날짜를 선택하면 선택 테두리가 표시되는지 확인합니다.

## 5. 날짜별 방문 기록

- 방문이 있는 날짜를 누르면 해당 날짜의 카페만 표시되는지 확인합니다.
- 카페 이름, 방문 시간, 별점, 메모가 올바르게 표시되는지 확인합니다.
- 방문 기록이 없는 날짜를 누르면 빈 상태 안내가 표시되는지 확인합니다.
- 날짜별 카페 카드를 누르면 해당 카페의 V42 방문 타임라인으로 이동하는지 확인합니다.

## 6. 데이터 변경 반영

- V42 방문 기록에서 새 방문을 추가합니다.
- 캘린더로 돌아왔을 때 날짜 배지와 월간 방문 횟수가 갱신되는지 확인합니다.
- 방문 기록을 수정하거나 삭제한 뒤 캘린더가 다시 계산되는지 확인합니다.
- 별점과 메모 수정이 날짜별 카드에 반영되는지 확인합니다.

## 7. 화면 이동

- 상단 `통계` 버튼이 V43 카페 방문 인사이트로 이동하는지 확인합니다.
- 하단 `전체 방문 기록 보기`가 V42 방문 기록으로 이동하는지 확인합니다.
- Android 뒤로 가기와 상단 뒤로 가기가 정상 동작하는지 확인합니다.

## 8. 데이터 없음

- 방문 기록이 없는 계정에서도 캘린더가 오류 없이 열리는지 확인합니다.
- 월간 지표가 0 또는 `-`로 안전하게 표시되는지 확인합니다.

## 9. 기존 기능 회귀

- V42 방문 기록 추가·수정·삭제가 정상 동작하는지 확인합니다.
- V43 방문 인사이트의 지표와 순위가 유지되는지 확인합니다.
- V44 `ROOT 카페 도전` 카드와 도전 화면이 유지되는지 확인합니다.
- 저장 카페 목록, 지도, 폴더 기능이 영향을 받지 않았는지 확인합니다.

## 완료 기준

위 항목을 실제 개발 빌드에서 모두 확인하면 V45 런타임 검증을 완료합니다.
