# ROOT V44 카페 방문 도전·마일스톤 실기기 테스트

## 목적

V42 방문 기록과 V43 방문 인사이트를 기반으로 V44 카페 방문 도전이 자동 계산되는지 확인합니다.

## 1. 진입

- 저장 카페 → 방문 기록 → 통계로 이동합니다.
- 카페 방문 인사이트 상단의 `ROOT 카페 도전` 카드를 누릅니다.
- `카페 방문 도전` 화면이 열리는지 확인합니다.

## 2. 기본 진행도

- 상단에 완료한 도전 수 / 전체 도전 수가 표시되는지 확인합니다.
- 전체 완료 퍼센트가 0~100% 범위로 표시되는지 확인합니다.
- 아직 완료하지 않은 도전 중 진행도가 가장 높은 항목이 `다음 달성에 가까운 도전`으로 표시되는지 확인합니다.

## 3. 방문 도전

- 방문 기록 1회 이상이면 `첫 카페 발자국`이 완료되는지 확인합니다.
- 누적 방문 5회 이상이면 `카페 산책가`가 완료되는지 확인합니다.
- 서로 다른 카페 3곳 이상 방문 시 `카페 탐험가`가 완료되는지 확인합니다.
- 서로 다른 카페 10곳 이상 방문 시 `카페 수집가`가 완료되는지 확인합니다.
- 한 카페를 3회 이상 방문하면 `나만의 단골집`이 완료되는지 확인합니다.
- 전체 방문 수에서 서로 다른 카페 수를 뺀 재방문 횟수가 `다시 찾는 이유`에 반영되는지 확인합니다.

## 4. 기록 도전

- 별점을 남긴 방문 기록이 `별점 기록가` 진행도에 반영되는지 확인합니다.
- 메모가 있는 방문 기록이 `카페 한 줄 일기` 진행도에 반영되는지 확인합니다.
- 별점 5점 기록이 `취향 확신` 진행도에 반영되는지 확인합니다.

## 5. 취향 도전

- 방문한 카페의 서로 다른 대표 테마 수가 `취향 넓히기`에 반영되는지 확인합니다.
- 서로 다른 방문 요일 수가 `요일 탐험`에 반영되는지 확인합니다.
- 현재 달의 방문 횟수가 `이번 달 카페데이`에 반영되는지 확인합니다.
- 누적 방문 30회가 `ROOT 카페 마스터` 진행도에 반영되는지 확인합니다.

## 6. 실시간 반영

- 방문 기록 화면에서 새 방문을 추가합니다.
- 도전 화면으로 돌아왔을 때 진행도가 자동 갱신되는지 확인합니다.
- 방문 기록의 별점이나 메모를 수정한 뒤 관련 도전 진행도가 갱신되는지 확인합니다.
- 방문 기록을 삭제한 뒤 진행도가 다시 내려가는지 확인합니다.

## 7. 이동

- 도전 화면의 `통계` 버튼이 카페 방문 인사이트로 이동하는지 확인합니다.
- 하단 `방문 기록 더 쌓기` 버튼이 방문 기록 화면으로 이동하는지 확인합니다.
- Android 뒤로 가기와 상단 뒤로 가기가 정상 동작하는지 확인합니다.

## 8. 데이터 없음

- 방문 기록이 없는 계정에서도 화면이 오류 없이 열리는지 확인합니다.
- 모든 도전 진행도가 0에서 시작하는지 확인합니다.

## 9. 기존 기능 회귀

- V42 방문 기록 추가·수정·삭제가 정상 동작하는지 확인합니다.
- V43 방문 인사이트의 총 방문, 방문 카페, 이번 달, 최근 30일, 자주 가요, 평균 별점이 유지되는지 확인합니다.
- 기존 저장 카페 목록, 지도, 폴더 기능이 영향을 받지 않았는지 확인합니다.

## 완료 기준

위 항목을 실제 개발 빌드에서 모두 확인하면 V44 런타임 검증을 완료합니다.
