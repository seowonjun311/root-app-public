# ROOT V46 카페 방문 상세 기록 런타임 체크리스트

## 목표

V42 방문 기록에 V46 상세 라이프로그 정보를 안전하게 추가하고,
기존 V43 인사이트, V44 챌린지, V45 방문 캘린더가 그대로 유지되는지 확인합니다.

## 1. 기존 데이터 호환

- [ ] V46 설치 전 생성한 기존 방문 기록이 정상적으로 보인다.
- [ ] 기존 방문 기록을 상세 화면으로 열었을 때 목적/동행/재방문 의향은 미선택 상태다.
- [ ] 기존 별점과 한 줄 메모가 그대로 유지된다.
- [ ] 기존 방문 기록의 수정/삭제가 계속 작동한다.

## 2. 방문 상세 화면 진입

- [ ] 카페별 방문 타임라인에서 문서 아이콘을 누르면 해당 방문 상세 화면이 열린다.
- [ ] V45 방문 캘린더에서 특정 날짜의 방문 카드를 누르면 해당 방문 상세 화면이 열린다.
- [ ] 상세 화면 상단에 카페명, 주소, 방문 시간이 표시된다.
- [ ] 상단 `타임라인` 버튼을 누르면 해당 카페의 방문 타임라인으로 이동한다.

## 3. 만족도

- [ ] 1~5점을 선택할 수 있다.
- [ ] 같은 점수를 다시 누르면 별점 선택이 해제된다.
- [ ] 저장 후 상세 화면을 다시 열어도 별점이 유지된다.

## 4. 방문 목적

- [ ] 공부
- [ ] 업무·노트북
- [ ] 데이트
- [ ] 대화·모임
- [ ] 커피·디저트
- [ ] 휴식
- [ ] 기타
- [ ] 하나를 선택한 뒤 같은 항목을 다시 누르면 선택이 해제된다.
- [ ] 다른 항목을 누르면 기존 선택 대신 새 항목이 선택된다.

## 5. 동행

- [ ] 혼자
- [ ] 친구
- [ ] 연인
- [ ] 가족
- [ ] 동료
- [ ] 기타
- [ ] 선택/해제와 변경이 정상적으로 저장된다.

## 6. 재방문 의향

- [ ] 또 가고 싶어요
- [ ] 생각해 볼래요
- [ ] 다시 가진 않을래요
- [ ] 선택/해제와 변경이 정상적으로 저장된다.

## 7. 한 줄 기록

- [ ] 기존 V42 한 줄 메모가 상세 화면에 표시된다.
- [ ] 최대 120자 제한이 유지된다.
- [ ] 수정 후 저장하면 방문 타임라인과 캘린더에도 변경된 메모가 표시된다.

## 8. 저장 상태

- [ ] 변경 전에는 `저장된 상태예요` 버튼이 비활성화된다.
- [ ] 하나라도 변경하면 `변경 내용 저장`으로 바뀌고 버튼이 활성화된다.
- [ ] 저장 완료 안내가 표시된다.
- [ ] 저장 후 버튼이 다시 비활성화 상태로 돌아온다.

## 9. 로컬/로그인 동기화

- [ ] 게스트 상태에서 상세 정보를 저장할 수 있다.
- [ ] 로그인 상태에서 상세 정보를 저장할 수 있다.
- [ ] 앱 재실행 후 상세 정보가 유지된다.
- [ ] 다른 기기 또는 새 세션에서 Firestore 동기화 후 동일한 상세 정보가 보인다.
- [ ] 기존 방문 클라우드 동기화에 오류가 생기지 않는다.

## 10. 회귀 테스트

- [ ] V42 방문 횟수와 최근 방문 계산이 정상이다.
- [ ] V43 방문 인사이트 화면이 정상이다.
- [ ] V44 챌린지/마일스톤 화면이 정상이다.
- [ ] V45 월간 방문 캘린더가 정상이다.
- [ ] 저장 카페 목록과 카페 상세 화면이 정상이다.

## 완료 기준

위 핵심 항목이 실기기에서 통과하면 V46 런타임 검증 완료로 처리합니다.
