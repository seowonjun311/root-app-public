# ROOT 카페 방문 기록·재방문 관리 실기기 테스트

현재 상태:

- V42 정적 검사 완료
- TypeScript 검사 완료
- 실기기 방문 기록 검증 보류

## 저장 카페 목록 연결

- [ ] 상단 방문 버튼이 전체 카페 방문 관리 화면을 연다.
- [ ] 각 카페 카드에 방문 기록 버튼이 표시된다.
- [ ] 방문 기록 버튼이 선택한 카페의 방문 타임라인을 연다.
- [ ] 기존 폴더에 담기와 상세 보기·수정 버튼이 그대로 작동한다.
- [ ] 기존 검색·관계·테마·계절 필터와 정렬이 유지된다.
- [ ] 기존 지도와 폴더 버튼이 유지된다.

## 카페 상세 화면 연결

- [ ] 조회 상태에서 방문 기록 버튼이 표시된다.
- [ ] 수정 상태에서는 방문 기록 버튼이 숨겨진다.
- [ ] 방문 기록 버튼이 현재 카페의 방문 타임라인을 연다.
- [ ] 나만의 폴더 버튼과 상세 수정 기능이 유지된다.

## 전체 방문 관리 화면

- [ ] 총 방문 횟수, 방문한 카페 수, 자주 가는 카페 수가 표시된다.
- [ ] 카페명과 주소를 검색할 수 있다.
- [ ] 전체·미방문·방문·자주 가요·최근 30일 필터가 작동한다.
- [ ] 방문 기록이 있는 카페가 최근 방문순으로 표시된다.
- [ ] 카페별 방문 횟수와 최근 방문일이 표시된다.
- [ ] 별점이 있으면 평균 별점이 표시된다.
- [ ] 오늘 방문 버튼이 방문 기록 입력 창을 연다.
- [ ] 기록 보기 버튼이 카페별 타임라인을 연다.

## 카페별 방문 타임라인

- [ ] 총 방문 횟수, 최근 방문일, 평균 별점이 표시된다.
- [ ] 오늘 방문 기록하기 버튼이 작동한다.
- [ ] 방문 기록이 최신순으로 표시된다.
- [ ] 방문 날짜와 시간이 표시된다.
- [ ] 별점과 한 줄 기록이 표시된다.
- [ ] 방문 기록 수정이 작동한다.
- [ ] 방문 기록 삭제 확인창이 작동한다.
- [ ] 기록이 없을 때 빈 상태 안내가 표시된다.

## 방문 기록 입력

- [ ] 별점 없이 방문만 기록할 수 있다.
- [ ] 별점 1~5점을 선택하고 다시 눌러 해제할 수 있다.
- [ ] 한 줄 기록은 최대 120자까지 입력된다.
- [ ] 저장 중 중복 터치가 차단된다.
- [ ] 수정 시 기존 별점과 기록이 불러와진다.
- [ ] 저장 후 요약 수치와 타임라인이 즉시 갱신된다.

## 데이터와 동기화

- [ ] 게스트 상태에서 방문 기록이 로컬에 저장된다.
- [ ] 로그인 후 게스트 방문 기록이 계정에 이어진다.
- [ ] 로그인 상태에서 `savedCafeVisitData`가 Firestore에 저장된다.
- [ ] 다른 기기에서 방문 기록이 병합된다.
- [ ] 한 기기에서 삭제한 방문 기록이 다른 기기에서 다시 살아나지 않는다.
- [ ] 저장 카페를 삭제하면 해당 카페의 방문 기록이 정리된다.
- [ ] 앱을 종료한 뒤 다시 열어도 방문 기록이 유지된다.
