# ROOT 카페 방문 인사이트 실기기 테스트

현재 상태:

- V43 정적 검사 완료
- TypeScript 검사 완료
- 실기기 방문 인사이트 검증 보류

## 진입

- [ ] 저장 카페 → 방문 기록 화면에서 `통계` 버튼이 보인다.
- [ ] `통계` 버튼을 누르면 카페 방문 인사이트 화면이 열린다.
- [ ] 인사이트 화면의 `기록` 버튼으로 방문 기록 화면에 돌아갈 수 있다.

## 요약 지표

- [ ] 총 방문 횟수가 V42 방문 기록과 일치한다.
- [ ] 실제 방문한 카페 수가 정확하다.
- [ ] 이번 달 방문 횟수가 정확하다.
- [ ] 최근 30일 방문 횟수가 정확하다.
- [ ] 3회 이상 방문한 카페가 `자주 가요` 수에 포함된다.
- [ ] 별점 기록이 있을 때 전체 평균 별점이 표시된다.
- [ ] 별점 기록이 없으면 `미입력`으로 표시된다.

## 방문 패턴

- [ ] 가장 많이 방문한 대표 테마가 취향 문장에 표시된다.
- [ ] 저장 카페 대비 실제 방문 비율이 표시된다.
- [ ] 가장 많이 방문한 요일이 표시된다.
- [ ] 방문 기록이 없을 때 빈 상태 안내가 표시된다.

## 순위

- [ ] `가장 자주 간 카페`가 방문 횟수 내림차순으로 표시된다.
- [ ] 동률이면 최근 방문한 카페가 먼저 표시된다.
- [ ] 3회 이상 방문한 카페에는 `자주 가요`가 표시된다.
- [ ] 순위 카페를 누르면 해당 카페 방문 타임라인으로 이동한다.
- [ ] 별점이 있는 카페는 `평점이 높은 카페`에 표시된다.
- [ ] 평점 동률이면 방문 횟수가 많은 카페가 먼저 표시된다.

## 테마·요일·별점

- [ ] 방문 테마 상위 5개가 실제 방문 횟수 기준으로 표시된다.
- [ ] 각 테마의 방문 카페 수와 방문 횟수가 표시된다.
- [ ] 일~토 요일별 방문 횟수가 정확하다.
- [ ] 별점 5~1점 분포가 정확하다.
- [ ] 별점 기록이 없으면 별점 분포 영역이 숨겨진다.

## 최근 방문

- [ ] 최근 방문 8개가 최신순으로 표시된다.
- [ ] 방문 날짜가 표시된다.
- [ ] 별점이 있으면 별점이 표시된다.
- [ ] 방문 메모가 있으면 한 줄로 표시된다.
- [ ] 최근 방문 카드를 누르면 해당 카페 방문 타임라인으로 이동한다.

## 데이터 갱신

- [ ] 방문 기록을 추가한 뒤 인사이트로 돌아오면 수치가 갱신된다.
- [ ] 방문 기록을 수정한 뒤 평균 별점과 최근 목록이 갱신된다.
- [ ] 방문 기록을 삭제한 뒤 순위·테마·요일 통계가 갱신된다.
- [ ] 게스트 방문 기록도 인사이트에 반영된다.
- [ ] 로그인 계정의 Firestore 동기화 방문 기록도 반영된다.

## 회귀 테스트

- [ ] V41 빠른 폴더 분류가 유지된다.
- [ ] V40 폴더 관리가 유지된다.
- [ ] V39 현재 위치·거리 필터가 유지된다.

- [ ] 새 패키지나 새 네이티브 빌드가 필요하지 않다.
