# ROOT V47 카페 취향·방문 통계 고도화 런타임 체크리스트

## 목표

V46에서 저장하는 방문 목적, 동행, 재방문 의향을 V43 인사이트 화면에 연결해
사용자의 실제 카페 취향과 최근 방문 패턴을 자동으로 보여주는지 확인합니다.

## 1. 기존 기능 회귀

- [ ] V42 카페 방문 기록이 그대로 보인다.
- [ ] V43 기존 방문 인사이트가 그대로 보인다.
- [ ] V44 카페 방문 챌린지 진입 버튼이 정상이다.
- [ ] V45 방문 캘린더 진입 버튼이 정상이다.
- [ ] V46 방문 상세 화면과 상세 저장이 정상이다.

## 2. 기존 방문 데이터 호환

- [ ] V46 이전에 만든 방문 기록만 있어도 인사이트 화면이 오류 없이 열린다.
- [ ] 목적/동행/재방문 의향이 없는 과거 기록은 분포 계산에서 제외된다.
- [ ] 총 방문, 방문 카페, 이번 달, 최근 30일, 자주 가요, 평균 별점 기존 수치는 유지된다.

## 3. 나의 카페 취향 요약

- [ ] 취향 기록 카드에 상세 필드가 하나 이상 입력된 방문 수가 표시된다.
- [ ] 상세 완성률은 목적+동행+재방문 의향이 모두 입력된 방문 비율로 표시된다.
- [ ] 또 가고 싶어요 비율은 재방문 의향을 입력한 방문만 기준으로 계산된다.
- [ ] 최근 30일 기록 비율이 정상적으로 표시된다.
- [ ] 가장 많이 기록한 방문 목적이 취향 요약에 표시된다.
- [ ] 가장 많이 기록한 동행 유형이 취향 요약에 표시된다.

## 4. 방문 목적 비율

- [ ] 공부
- [ ] 업무·노트북
- [ ] 데이트
- [ ] 대화·모임
- [ ] 커피·디저트
- [ ] 휴식
- [ ] 기타
- [ ] 실제 기록이 있는 항목만 표시된다.
- [ ] 횟수와 퍼센트가 목적 입력 건수 기준으로 계산된다.

## 5. 동행 비율

- [ ] 혼자
- [ ] 친구
- [ ] 연인
- [ ] 가족
- [ ] 동료
- [ ] 기타
- [ ] 실제 기록이 있는 항목만 표시된다.
- [ ] 횟수와 퍼센트가 동행 입력 건수 기준으로 계산된다.

## 6. 재방문 의향

- [ ] 또 가고 싶어요
- [ ] 생각해 볼래요
- [ ] 다시 가진 않을래요
- [ ] 횟수와 퍼센트가 정상적으로 계산된다.

## 7. 최근 30일 취향 패턴

- [ ] 최근 30일 방문 횟수가 기존 통계와 일치한다.
- [ ] 최근 30일 상세 기록 횟수와 비율이 표시된다.
- [ ] 최근 30일 주된 방문 목적이 표시된다.
- [ ] 최근 30일 주된 동행 유형이 표시된다.
- [ ] 최근 30일 `또 가고 싶어요` 비율이 표시된다.

## 8. 상황별 자주 간 카페

- [ ] 공부 목적으로 가장 많이 방문한 카페가 표시된다.
- [ ] 데이트 목적으로 가장 많이 방문한 카페가 표시된다.
- [ ] 혼자 가장 많이 방문한 카페가 표시된다.
- [ ] 해당 유형의 방문 기록이 없으면 그 카드는 표시되지 않는다.
- [ ] 카드를 누르면 해당 카페 방문 타임라인으로 이동한다.

## 9. 다시 가고 싶은 카페

- [ ] `또 가고 싶어요`로 기록한 카페를 최대 5곳까지 보여준다.
- [ ] 같은 카페에 여러 번 `또 가고 싶어요`를 남기면 횟수가 누적된다.
- [ ] 횟수가 같으면 더 최근에 방문한 카페가 위에 표시된다.
- [ ] 카드를 누르면 해당 카페 방문 타임라인으로 이동한다.

## 10. 실시간 반영

- [ ] V46 상세 화면에서 목적을 수정한 뒤 인사이트로 돌아오면 값이 갱신된다.
- [ ] 동행을 수정한 뒤 인사이트로 돌아오면 값이 갱신된다.
- [ ] 재방문 의향을 수정한 뒤 인사이트로 돌아오면 값이 갱신된다.
- [ ] 앱 재실행 후에도 동일한 통계가 계산된다.
- [ ] 로그인 사용자 Firestore 동기화 후에도 동일한 통계가 보인다.

## 완료 기준

위 핵심 항목이 실기기에서 통과하면 V47 런타임 검증 완료로 처리합니다.
