# CHARACTER V101D – Floating Walk-State Animation 실기기 체크리스트

## 목표

화면 위 캐릭터가 실제로 위치를 이동하는 동안에는 walk 01~04 프레임만 재생하고,
멈춰 쉬는 동안에는 기존 idle 01~04 프레임으로 돌아오는지 확인한다.

## 테스트

- [ ] ROOT → 캐릭터 Preview → 화면 위 캐릭터에서 자동 이동 ON
- [ ] 다른 앱(카카오톡 등)으로 이동
- [ ] 2~5초 정지 구간에서는 idle 애니메이션으로 보임
- [ ] 자율 이동이 시작되는 순간 walk 애니메이션으로 전환됨
- [ ] 이동 중 앉기/정지 모습으로 미끄러지지 않음
- [ ] 목표 위치에 도착하면 walk가 멈추고 idle로 복귀
- [ ] 한 손가락으로 캐릭터를 드래그하면 walk 애니메이션
- [ ] 손을 떼면 idle로 복귀
- [ ] 손을 뗀 약 4초 뒤 자율 이동이 재개되고 다시 walk로 전환
- [ ] 두 손가락 확대/축소 중에는 walk 상태로 오인되지 않음
- [ ] 60~160% 크기 설정 유지
- [ ] 위치/크기/자동 이동 설정 유지
- [ ] 다른 앱 위 표시/탭하여 ROOT 열기/알림 숨기기 유지
