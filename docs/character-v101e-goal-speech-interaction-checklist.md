# CHARACTER V101E – 행동목표 말풍선 + 터치 상호작용 실기기 체크리스트

## 사전 조건

- V101D 설치 완료
- 아직 EAS 새 빌드를 만들지 않아도 됨
- V101D와 V101E를 모두 설치한 뒤 마지막에 한 번만 새 Development Build 생성

## 짧게 누르기

- [ ] 화면 위 캐릭터를 짧게 한 번 누름
- [ ] ROOT 앱이 바로 열리지 않음
- [ ] 캐릭터 근처에 짧은 반응 말풍선이 표시됨
- [ ] 반응 말풍선이 약 2~3초 뒤 자동으로 사라짐
- [ ] 자동 이동은 사용자 상호작용 후 기존처럼 잠시 쉬었다 재개됨

## 길게 누르기

- [ ] 캐릭터를 약 0.65초 이상 길게 누름
- [ ] `캐릭터 끄기` / `ROOT 가기` 메뉴가 표시됨
- [ ] `ROOT 가기`를 누르면 ROOT가 열리고 플로팅 캐릭터는 유지됨
- [ ] `캐릭터 끄기`를 누르면 foreground overlay 서비스가 종료되고 캐릭터가 사라짐
- [ ] 메뉴가 열린 동안 자동 이동하지 않음
- [ ] 메뉴를 선택하지 않으면 약 7초 후 자동으로 닫힘

## 행동목표 말풍선

- [ ] ROOT 홈의 현재 행동목표가 네이티브 스냅샷으로 동기화됨
- [ ] 요일 지정 목표는 오늘 요일에 해당할 때만 후보가 됨
- [ ] 주 N회 목표는 이번 주 목표 횟수를 아직 채우지 않았을 때 후보가 됨
- [ ] 오늘 완료한 목표는 후보에서 제외됨
- [ ] 화면 위 캐릭터 설정에 `행동목표 말해주기` ON/OFF가 표시됨
- [ ] 설정에 현재 미완료 목표 개수가 표시됨
- [ ] `지금 말해보기`를 누르면 즉시 목표 말풍선을 시험할 수 있음
- [ ] 자동 목표 말풍선은 이동 중이 아니라 멈춰 있을 때 표시됨
- [ ] 같은 목표 하나만 남은 경우 30분 이내 과도하게 반복하지 않음
- [ ] 일반 자동 말풍선 주기는 약 10~20분
- [ ] 말풍선이 떠 있는 동안 캐릭터가 미끄러지듯 이동하지 않음

## V101C/V101D 회귀

- [ ] 자율 이동 ON/OFF 유지
- [ ] 이동 중 walk 01~04 / 정지 중 idle 01~04 유지
- [ ] 한 손가락 드래그 유지
- [ ] 두 손가락 확대/축소 유지
- [ ] 60~160% 설정 크기 조절 유지
- [ ] 위치/크기/자동 이동 설정 재실행 후 유지
- [ ] 다른 앱 위 표시 유지
