# CHARACTER V101F – 행동목표 완료 축하 실기기 체크리스트

## 목표
사용자가 ROOT에서 행동목표를 완료했을 때 화면 위 캐릭터가 같은 완료에 정확히 한 번만 반응하고,
happy/jump 애니메이션과 축하 말풍선을 보여주는지 확인한다.

## 테스트
- [ ] 플로팅 캐릭터를 켠 상태에서 아직 완료하지 않은 행동목표를 하나 준비
- [ ] ROOT에서 해당 행동목표를 완료
- [ ] 완료 직후 플로팅 캐릭터의 자동 이동이 잠시 멈춤
- [ ] 캐릭터가 happy 01→02→03 기반 점프/기쁨 애니메이션을 재생
- [ ] 목표 제목이 포함된 축하 말풍선이 약 5초 표시
- [ ] 축하 후 idle로 복귀하고 기존 자동 이동이 다시 이어짐
- [ ] 같은 목표 상태가 다시 동기화되어도 축하가 반복되지 않음
- [ ] 앱을 재실행해도 이미 축하한 동일 날짜/동일 목표를 다시 축하하지 않음
- [ ] 플로팅 캐릭터를 꺼둔 동안 완료한 목표는 나중에 캐릭터를 켰을 때 뒤늦게 축하하지 않음
- [ ] 다른 목표를 새로 완료하면 그 목표는 별도로 한 번 축하
- [ ] 짧은 터치 반응 유지
- [ ] 길게 누르기 → 캐릭터 끄기 / ROOT 가기 유지
- [ ] 자동 이동 중 walk / 정지 중 idle 유지
- [ ] 두 손가락 확대·축소와 60~160% 설정 유지
- [ ] 행동목표 일반 말풍선 기능 유지
