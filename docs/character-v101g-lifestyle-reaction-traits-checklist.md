# CHARACTER V101G – 생활 반응 + 캐릭터별 말투 실기기 체크리스트

## 목표

ROOT의 행동목표와 하루 가계부 원본을 수정하지 않고 읽기만 하면서,
플로팅 캐릭터가 선택 캐릭터에 맞는 말투로 목표를 독려/칭찬하고
오늘 고정 배정 예산 대비 실제 지출에 따라 칭찬 또는 잔소리를 하는지 확인한다.

## 플로팅 커뮤니케이션 성향

- 루티: 균형형
- 모루: 적극적인 코치/잔소리형
- 몽실: 부드러운 위로형
- 다미: 칭찬이 많은 응원형
- 피오: 탐험·여행 제안형
- 누리: 성취·미션형
- 토리: 조용하고 부드러운 독려형

기존 캐릭터 이동/휴식 personality policy는 수정하지 않는다.
V101G 성향은 플로팅 말풍선의 표현과 생활 반응 확률에만 적용한다.

## 행동목표

- [ ] 같은 미완료 행동목표라도 선택 캐릭터에 따라 말투가 다름
- [ ] V101F 목표 완료 축하도 선택 캐릭터별 말투가 다름
- [ ] 다미는 칭찬 표현이 강함
- [ ] 모루는 목표 독려/지출 잔소리 반응 확률이 높음
- [ ] 피오는 목표/지출 문장에 여행·탐험 느낌이 섞임
- [ ] 몽실/토리는 잔소리가 비교적 부드러움

## 가계부

- [ ] 하루 탭에서 현재 월 목표 예산을 먼저 설정
- [ ] 취소되지 않은 expense만 지출 합계에 사용
- [ ] 기존 월 예산 ÷ 그 달 날짜 수의 고정 일간 배정 예산과 동일한 기준 사용
- [ ] 오늘 지출이 고정 일간 예산의 30~65% 구간에 처음 진입할 때 칭찬 후보 발생
- [ ] 오늘 지출이 고정 일간 예산 100%를 처음 넘을 때 잔소리 후보 발생
- [ ] 오늘 지출이 고정 일간 예산 150%를 처음 넘을 때 강한 잔소리 발생
- [ ] 같은 날짜의 같은 지출 신호는 반복되지 않음
- [ ] 첫 연결 시 이미 존재하던 지출 상태를 갑자기 과거 반응으로 재생하지 않음
- [ ] 플로팅 캐릭터가 꺼져 있을 때 저장한 지출을 켠 뒤 뒤늦게 재생하지 않음
- [ ] 월 예산이 없는 경우 금액만 보고 임의로 잔소리하지 않음

## 회귀

- [ ] 짧게 터치 → 캐릭터 반응 유지
- [ ] 길게 누르기 → 캐릭터 끄기 / ROOT 가기 유지
- [ ] 이동 중 walk / 정지 중 idle 유지
- [ ] 목표 완료 → happy + 1회 축하 유지
- [ ] 일반 행동목표 말풍선 유지
- [ ] 확대·축소 / 60~160% / 자동 이동 / 위치 저장 유지
