# CHARACTER V101H – 시간대 + 상태 기반 말풍선 실기기 체크리스트

## 목표

플로팅 캐릭터가 기기 현지 시간과 기존 `rooty_state_v1`의 mood/energy/affection을
읽기 전용으로 참고해 목표 독려 강도를 조절하고 자연스러운 시간대 말풍선을 보여주는지 확인한다.

## 시간대

- [ ] 06:00~10:59 아침: 좋은 아침/오늘 목표 시작 계열
- [ ] 11:00~16:59 낮: 오늘 진행 상황/완료 칭찬 계열
- [ ] 17:00~21:59 저녁: 남은 목표 정리 계열
- [ ] 22:00~05:59 늦은 밤: 목표 독촉보다 휴식 권유 우선
- [ ] 같은 날짜 + 같은 시간대 + 같은 상태 신호를 계속 반복하지 않음

## 상태

V59와 같은 경계값을 사용한다.

- [ ] energy 0~24: exhausted → 목표보다 휴식 우선
- [ ] energy 25~49: tired → 쉬었다 다시 하자는 말
- [ ] mood 0~29: low → 강한 독촉 대신 응원/완화
- [ ] energy 75~100 + 미완료 목표: 적극적인 시작 제안
- [ ] affection 75~100: 일부 시간/상태 문구가 더 친근해짐

## 기존 생활 반응과 결합

- [ ] 늦은 밤에 예산 초과가 발생하면 잔소리 문구가 부드러워짐
- [ ] low mood 상태에서도 지출 잔소리가 공격적으로 강해지지 않음
- [ ] 정상 시간/정상 기분에서는 V101G의 지출 칭찬·잔소리 기준 유지

## 목표가 없는 경우

- [ ] 미완료 행동목표가 0개여도 목표·상태 말풍선 스케줄이 완전히 멈추지 않음
- [ ] `지금 말해보기`로 현재 시간/상태 메시지를 확인할 수 있음

## 회귀

- [ ] 짧게 터치 캐릭터별 반응 유지
- [ ] 길게 누르기 → 캐릭터 끄기 / ROOT 가기 유지
- [ ] walk / idle 유지
- [ ] 목표 완료 → happy + 1회 축하 유지
- [ ] V101G 캐릭터별 목표/완료/지출 말투 유지
- [ ] 확대·축소 / 자동 이동 / 위치 저장 유지
