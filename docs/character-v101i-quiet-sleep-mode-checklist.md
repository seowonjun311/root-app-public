# CHARACTER V101I – 방해 금지 / 수면시간 / 빠른 조용히 체크리스트

## 기본 동작

- [ ] 최초 기본 수면시간은 23:00~07:00
- [ ] 설정에서 시작/종료 시간을 1시간 단위로 자유롭게 변경 가능
- [ ] 자정을 넘는 시간(예: 23:00~07:00)이 정상 처리됨
- [ ] 수면시간 ON/OFF 가능
- [ ] `수면 시간 자동 이동 멈춤` ON/OFF 가능

## 수면시간

- [ ] 수면시간에 자동 목표 말풍선이 나오지 않음
- [ ] 시간대/상태 말풍선이 나오지 않음
- [ ] 가계부 칭찬/잔소리가 나오지 않음
- [ ] 목표 완료 이벤트가 수면시간에 발생해도 나중에 뒤늦게 축하하지 않음
- [ ] 자동 이동 멈춤 ON이면 수면시간에 idle 상태로 멈춤
- [ ] 수면시간 종료 후 기존 자동 이동 설정이 ON이었다면 다시 이동
- [ ] 저장된 자동 이동 사용자 설정 자체는 바뀌지 않음

## 빠른 조용히

- [ ] 30분 버튼
- [ ] 1시간 버튼
- [ ] 2시간 버튼
- [ ] 빠른 조용히 해제 버튼
- [ ] 빠른 조용히 중 자동 말풍선이 나오지 않음
- [ ] 빠른 조용히는 캐릭터 자동 이동을 강제로 끄지 않음
- [ ] 시간이 끝나면 자동으로 일반 모드 복귀

## 사용자 직접 상호작용

- [ ] 조용히 모드에서도 짧게 터치하면 캐릭터가 반응
- [ ] 길게 누르면 `캐릭터 끄기 / ROOT 가기` 메뉴가 정상 표시
- [ ] 드래그/핀치 확대축소 정상

## 회귀

- [ ] V101H 시간대/상태 말풍선 유지
- [ ] V101G 지출 칭찬·잔소리 및 캐릭터별 말투 유지
- [ ] V101F 완료 happy/1회 처리 유지
- [ ] V101D walk / idle 유지
- [ ] V101C 위치·크기·자동이동 저장 유지

오래 정지 → sit → sleep / 목표완료 → happy / 짧은 터치 → touch/happy 상태 머신을 연결한다.
