# CHARACTER V101J – 플로팅 행동 애니메이션 상태 머신

## 자연 상태
- [ ] 이동: walk 01~04
- [ ] 이동 정지: idle
- [ ] 약 2.2초 정지: sit 01~04
- [ ] 약 4.2초 정지: sleep 01~05
- [ ] sleep 후 04/05 호흡 루프
- [ ] 자연 sleep 약 5초 후 idle 복귀
- [ ] 이동 재개 시 즉시 walk

## 수면시간
- [ ] V101I 수면시간 + 자동 이동 멈춤 ON → 실제 sleep 유지
- [ ] 수면시간 종료 → 강제 sleep 해제
- [ ] 기존 자동 이동 ON이면 다시 자연 이동
- [ ] 자동 이동 멈춤 OFF이면 기존 이동 정책 유지

## 터치
- [ ] 짧게 터치 → touch 01→02→01
- [ ] 기존 짧은 터치 말풍선 유지
- [ ] 길게 누르기 → 캐릭터 끄기 / ROOT 가기
- [ ] 드래그 → walk
- [ ] 핀치 확대축소 정상

## 목표 완료
- [ ] 목표 완료 → 기존 V101F happy
- [ ] happy 중 sit/sleep 끼어들지 않음
- [ ] happy 종료 후 자연 상태 복귀
- [ ] 같은 목표 완료 1회 처리 유지

## 캐릭터
루티/모루/몽실/다미/피오/누리/토리 각각:
- [ ] sit 4장
- [ ] sleep 5장
- [ ] touch 2장
- [ ] 다른 캐릭터 이미지로 바뀌지 않음
- [ ] 흰 플래시/사라짐 없음

토리:
- [ ] 기존 happy 3장 예외 유지
- [ ] tori_happy_04를 요구하지 않음
