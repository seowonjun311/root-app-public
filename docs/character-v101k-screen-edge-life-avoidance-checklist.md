# CHARACTER V101K – 화면 가장자리 생활감 + 키보드/중요영역 회피

## 화면 가장자리 생활감

- [ ] 자동 이동 시 캐릭터가 화면 최상단에 자주 붙지 않음
- [ ] 좌우 화면 밖으로 잘리지 않음
- [ ] 하단 시스템 영역에 지나치게 붙지 않음
- [ ] 가끔 화면 아래쪽 좌/우 안전 가장자리 부근에 머물러 생활감이 생김
- [ ] 중앙만 반복 왕복하지 않음
- [ ] 가장자리에서 바깥쪽으로 계속 밀려붙지 않고 안쪽 목표를 잡음

## 키보드 회피

- [ ] 카카오톡/메모/브라우저 등에서 키보드가 올라왔을 때 자동 이동 중이면 캐릭터 목표점이 키보드 위로 보정됨
- [ ] 이미 아래쪽에 있던 캐릭터도 자동 이동 ON 상태라면 키보드 위쪽으로 이동
- [ ] 키보드가 내려가면 다시 정상 안전영역 전체를 사용
- [ ] 23:00~07:00 수면시간 + 자동이동 멈춤 상태에서도 키보드가 캐릭터를 덮으면 sleep 자세를 유지한 채 위로 한 번 보정 가능
- [ ] 자동 이동 OFF를 사용자가 직접 선택한 경우 V101K가 일반 자동 이동을 강제로 켜지 않음

## 사용자 중요영역 학습

- [ ] 캐릭터가 버튼/텍스트 등을 가려서 사용자가 약 52dp 이상 멀리 드래그하면 기존 위치를 임시 회피영역으로 기억
- [ ] 이후 자동 이동이 잠시 그 위치를 다시 덮지 않음
- [ ] 최대 3개 영역을 약 8분 동안 기억
- [ ] 사용자가 회피영역 안으로 캐릭터를 직접 다시 가져다 놓으면 해당 회피 의도를 해제
- [ ] 앱을 다시 시작하면 이 임시 회피 기억은 초기화되어 오래된 화면 구조를 잘못 기억하지 않음

## 개인정보/권한

- [ ] 다른 앱의 버튼 이름이나 화면 내용을 읽지 않음
- [ ] AccessibilityService 추가 없음
- [ ] 접근성 권한 추가 요청 없음
- [ ] AndroidManifest 변경 없음
- [ ] 중요영역 회피는 화면 좌표 + 사용자의 드래그 행동만 사용

## V101J 회귀

- [ ] idle → sit → sleep → idle
- [ ] 이동 → walk
- [ ] 짧은 터치 → touch
- [ ] 목표 완료 → happy
- [ ] 루티 legacy sit4/sleep1/touch fallback 유지
- [ ] 토리 happy3 예외 유지

## V101A~I 회귀

- [ ] 드래그/핀치/크기/위치 저장
- [ ] 목표 말풍선/시간대/상태 말풍선
- [ ] 지출 칭찬·잔소리
- [ ] 방해금지/빠른 조용히
- [ ] 길게 누르기 → 캐릭터 끄기 / ROOT 가기
