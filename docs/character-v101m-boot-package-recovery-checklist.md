# CHARACTER V101M – 재부팅·앱 업데이트 후 플로팅 캐릭터 복구

## 사용자 의도 보존

- [ ] 플로팅 캐릭터를 켠 상태에서 정상 사용 후 휴대폰 재부팅 → 부팅 완료 후 캐릭터 복구
- [ ] 플로팅 캐릭터를 직접 끈 뒤 휴대폰 재부팅 → 캐릭터가 자동으로 다시 켜지지 않음
- [ ] 캐릭터를 직접 끈 뒤 앱을 새 개발 빌드로 업데이트 → 자동 복구되지 않음
- [ ] 캐릭터를 켠 상태에서 앱 업데이트 → 새 패키지 설치 완료 후 복구 시도

## 권한

- [ ] 다른 앱 위에 표시 권한이 유지된 상태 → 복구 가능
- [ ] 다른 앱 위에 표시 권한을 제거한 상태 → 재부팅/업데이트 후 강제 실행하지 않음
- [ ] 권한을 다시 허용한 뒤 ROOT에서 캐릭터를 직접 켜면 정상 동작

## 상태 복구

- [ ] 선택 캐릭터 유지
- [ ] 크기 유지
- [ ] 마지막 위치/화면 비율 보정 유지
- [ ] 자동 이동 ON/OFF 유지
- [ ] 목표 말풍선 ON/OFF 유지
- [ ] 수면시간/빠른 조용히 설정 유지
- [ ] V101L 화면 OFF/ON 배터리 정책 유지

## 시스템 이벤트

- [ ] `BOOT_COMPLETED` 수신 후 중복 캐릭터가 생성되지 않음
- [ ] `MY_PACKAGE_REPLACED` 수신 후 중복 foreground service가 생성되지 않음
- [ ] receiver 예외가 앱/부팅 프로세스를 crash시키지 않음
- [ ] `LOCKED_BOOT_COMPLETED`는 사용하지 않음

## 회귀

- [ ] 짧은 터치 반응 정상
- [ ] 길게 누르기 메뉴 정상
- [ ] 드래그/핀치 정상
- [ ] walk/sit/sleep/happy 상태 정상
- [ ] 키보드 회피 정상
- [ ] 화면 회전/해상도 변경 정상
- [ ] ROOT 앱 최근 앱 제거 후 플로팅 유지 정상
