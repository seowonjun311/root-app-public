# ROOT 탐험 V1.0 공통 장소 · ROOT 장소 미리보기

## 목표

기존 대한민국 탐험 → 지역 → 자치구 실제 지도 흐름을 유지하면서
장소 탐색을 카테고리별로 확장할 수 있는 공통 기반을 추가한다.

이번 단계는 UI/검색 기반이며 기존 방문/미방문 필터와 함께 동작한다.
실제 사용자 사진 업로드·후기·제보 Firestore 쓰기는 다음 단계에서 연결한다.

## 공통 장소 테마

- 전체
- 카페
- 야장
- 노포
- 맛집
- 자연

야장/노포는 서로 배타적인 카테고리가 아니다.
한 장소가 동시에 `맛집 + 야장 + 노포`로 검색될 수 있다.

## 지도

- [ ] `장소명 또는 #야장 #노포로 검색` 입력창이 표시된다.
- [ ] 장소명 검색이 지도 마커와 아래 목록에 동시에 적용된다.
- [ ] `#야장`, `#노포`처럼 앞에 #을 붙여도 검색된다.
- [ ] 검색어 지우기 버튼이 작동한다.
- [ ] 기존 자치구 MapView가 정상 표시된다.
- [ ] 기존 탐험 장소 마커가 정상 표시된다.
- [ ] 야장 필터를 누르면 야장 키워드가 있는 장소만 남는다.
- [ ] 노포 필터를 누르면 노포 키워드가 있는 장소만 남는다.
- [ ] 카페/맛집/자연 필터가 각각 작동한다.
- [ ] 방문/미방문 기존 필터와 테마 필터를 함께 사용할 수 있다.
- [ ] 축제·행사 탭이 유지된다.
- [ ] 예약·시설 탭이 유지된다.

## ROOT 장소 미리보기

- [ ] React Native 지원 font weight만 사용한다.
- [ ] 장소 카드 스타일이 `ViewStyle | TextStyle | ImageStyle` union 오류를 만들지 않는다.


장소 마커를 누르면 기존 작은 한 줄 카드 대신 ROOT 스타일 카드가 표시된다.

- [ ] 대표 사진이 있으면 이미지가 표시된다.
- [ ] 이미지가 없으면 장소 아이콘 + `사진 준비 중`이 표시된다.
- [ ] 장소명·태그·주소가 표시된다.
- [ ] `저장 / 길찾기 / 공유` 3개 버튼이 표시된다.
- [ ] 길찾기가 지도 앱/웹 지도를 연다.
- [ ] 공유가 Android 공유 시트를 연다.
- [ ] 홈 / 사진 / 후기 탭 UI가 표시된다.
- [ ] `함께 만들어가는 장소` 영역이 표시된다.
- [ ] 사진 추가하기
- [ ] 영업시간 제보
- [ ] 웨이팅 현황
- [ ] 최근 제보 하이라이트

## 이번 단계의 의도적인 보류

아래 기능은 V1.1~V1.3에서 순서대로 연결한다.

1. 공통 장소 저장 Store / Firestore
2. 사용자 사진·동영상 업로드
3. 영업시간·웨이팅·야외석·우천 제보 저장
4. 지도 줌 레벨 기반 숫자 클러스터
5. 확대 시 사용자 사진 원형 마커
6. 서울 야장·노포 검증 데이터 import
7. 새 장소 추가 / 검수 대기 / 승인 흐름
