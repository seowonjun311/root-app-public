# ROOT 탐험 V1.1 지도 숫자 클러스터 · 사진 마커

## 목표

V1.0의 공통 장소 검색/필터/ROOT 장소 카드를 유지하면서
지도 줌 레벨에 따라 장소 표시 방식을 바꾼다.

## 지도 동작

V1.1 v2는 `onMapReady` 주변의 정확한 공백/프로퍼티 순서에 의존하지 않고
`ref={mapRef}`가 있는 실제 MapView opening tag를 구조적으로 찾아
`onRegionChangeComplete`를 삽입한다.

### 멀리 보기

- [ ] 개별 아이콘 대신 ROOT 갈색 원형 숫자 클러스터가 보인다.
- [ ] `1`, `5`, `12`처럼 해당 영역의 필터 적용 장소 수가 표시된다.
- [ ] 야장 필터 ON 시 야장에 해당하는 장소만 클러스터 숫자에 포함된다.
- [ ] 노포 필터 ON 시 노포에 해당하는 장소만 클러스터 숫자에 포함된다.
- [ ] 방문/미방문 기존 필터도 숫자에 함께 반영된다.
- [ ] 클러스터를 누르면 해당 영역 중심으로 확대된다.

### 가까이 보기

`latitudeDelta <= 0.03` 부근부터 개별 장소 모드로 전환한다.

- [ ] 대표 이미지 URL이 있는 장소는 원형 사진 마커로 표시된다.
- [ ] 사진이 아직 없는 장소는 기존 장소 아이콘을 ROOT 원형 마커 안에 표시한다.
- [ ] 선택된 장소 마커가 조금 커진다.
- [ ] 방문 완료 장소에는 초록 체크 배지가 유지된다.
- [ ] 장소 마커 터치 시 V1.0 ROOT 스타일 상세 미리보기 카드가 열린다.

## 사진 우선순위

이번 단계에서는 V1.0의 `getRootExplorePlaceImageUrl()`을 사용한다.

지원 후보:
- thumbnailImageUrl
- representativeImageUrl
- mainImageUrl
- imageUrl
- photoUrl
- mainImage
- image

V1.2에서 사용자 사진/동영상 Firestore 저장과 최신 현장사진 우선순위를 실제 연결한다.

## 성능

- 숫자 클러스터 모드에서는 전체 필터 장소를 약 5 x 5 그리드로 묶는다.
- 가까이 보기에서는 기존 지연 렌더링 `visiblePlaceMarkerItems`를 유지한다.
- 사진 마커가 로딩될 시간을 위해 close zoom에서 marker view tracking을 1.2초 유지한다.
- 외부 clustering 패키지를 추가하지 않는다.
